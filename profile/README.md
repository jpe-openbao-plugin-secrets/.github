# Jacob's OpenBao Secrets Plugins 🔐

**Keeping secrets is our Bao-nus.** OpenBao secrets engine plugins that mint
short-lived, dynamic credentials, because the best secret is one that expires
before anyone can lose it.

## Start here

The first public plugin is still warming up. Until it lands, the story so far
lives at [docs.jacobpevans.com](https://docs.jacobpevans.com).
